# 踩坑清单（每条都是真踩过的）

## 一、动画

| 坑 | 现象 | 解法 |
|---|---|---|
| **词缀与词根之间出现缝隙** | 两个 span 分开写，中间有空白 | 两个 `<span>` 必须写在同一行，不能换行 |
| **形变中间态扭成锯齿** | 换场时线形变得像麻花 | 4 顶点必须严格「左顶 左底 右底 右顶」，左端两点都在左侧 |
| **表情撑破球体** | 球被压扁时眼睛溢出轮廓 | 表情按 `min(rx,ry)` 等比缩放（母版已处理），别手改 |
| **钩爪缩成一圈箍** | 环心放在球心，整个环被球盖住 | 环心贴球缘：`cx = 球心 + rx + 1`，R ≈ 11 |
| **道具线看不见** | 沿内壁画的速度线被 3.2px 黑线吃掉 | 沿法向朝内平移（约 6px），保持与壁平行 |
| **冻结态球和钩爪糊成一个字** | 球的「受惊橙」提前变回蓝，与蓝钩爪同色 | 变色回落推到解冻之后（≥4.40s） |
| **拖影变成两个孤立椭圆** | 用 `<ellipse>` 做拖尾 | 拖影必须用 `bodyD()` 画同形残影，颜色跟随 `tint` |
| **手臂像悬空小钩子** | 按 ang+len 从球心往外画，末端脱离主体 | 改用目标点 `{tx,ty,grip}`，距离过近自动隐藏 |

## 二、声音

| 坑 | 现象 | 解法 |
|---|---|---|
| **整片音画差 2.6s** | 画面 OFFSET 偏移了，音轨没偏 | `OFFSET = 0`，画面时间 T 与音轨时间 t 恒等 |
| **TTS 前后带大段静音** | 原始 1.6–1.9s，真人声只有 0.5–0.7s | `silenceremove` −42dB / 首 0.02s / 尾 0.06s |
| **混音顶到 0dB 削波** | 按峰值归一后又拉一次 | 只按 RMS 归一，峰值仅在上限时轻压 |
| **人声被撞击声盖住** | SFX 峰值 0.47，人声 −20dB RMS | 人声侧链：BGM 压 48%、SFX 压 70% |
| **mp3 编码延迟** | 逐条拼接后整体后移 | 一律转 wav 44.1k 单声道再入轨 |
| **渐入噪声判错起音** | swish / whoosh 用能量峰值判起点，误报 46–60ms | 改用「首次超基线阈值」判据 |

## 四、验收标准

| 项 | 标准 | 怎么测 |
|---|---|---|
| 冻结段静止 | 段内两帧 PSNR > 45 dB | 抽两帧比 |
| 冻结→解冻 | PSNR 明显低（约 18 dB） | 抽两帧比 |

## 五、做 rupt 短片时新增的坑（2026-10-27）

| 坑 | 现象 | 解法 |
|---|---|---|
| **`parts` 命名冲突** | 场景里写 `parts(t)` 当粒子函数，直接顶掉母版的词素分解字段，报 `s.parts.map is not a function` | 粒子函数必须叫 **`particles(t)`**；`parts` 是 `[[词缀, 释义]]` 专用 |
| **默认道具错配** | 母版 `updateProps` 按场景索引硬编码了 tract 的七件道具；只有 2 场的 rupt 里，第 2 场被塞进 attract 的吸力线，画面上多出一堆蓝色短线 | 母版已加守卫：`if (SCENES.length !== 7) return;` —— 注意这只在**不是 7 场**时生效；7 场的词根仍会跑 tract 的默认道具，所以**每场必须自己写 `props(t)`**（空也要写） |
| **tts 与音轨文件名不一致** | `tts.py` 输出 `w_<word>.wav`，`make-audio.js` 找 `w_<word>_f.wav`，配音静默丢失 | `make-audio.js` 已改成先找无后缀、再回退带音色后缀 |
| **极端形变时拖影碎成怪形** | 球压成一滩（rx/ry > 2）时，同形残影在几个位置各画一条扁片，看起来像随机蓝色碎片 | `updateTrail` 已加比例守卫：`max(rx,ry)/min(rx,ry) > 2.0` 就不画残影 |

## 六、写动作时的两条经验

1. **动作要铺满整场，别留空窗。** 每场动画 5.2s（冻结在 4.42s），主事件放在 0.05–1.6，中间必须再补一段（余震、二次弹跳、配角走位），否则 1.6–4.4 会是一张静止图。
2. **副角的动作要晚于主角。** 主角演完、副角才开始移动，能把尾段填满，也符合"反应"的因果顺序。

## 七、做 port 家族与"球变卡车"时新增的坑（2026-10-27）

| 坑 | 现象 | 解法 |
|---|---|---|
| **形变中间态打结** | 圆形变车形时形状翻卷、扭成麻花 | 采样必须**按角度**（每条射线取最远交点），不能用弧长等分 |
| **形变底边出锯齿** | 车底比球底高，底部提前收缩时相邻角度不同步，边缘像破布 | 底部延迟用 `sin` 权重**连续**过渡（`delay *= 1 - 0.75*max(0,sin(a))`），不能按角度区间硬切 |
| **缩回时细节浮在车外** | 车形缩回球，窗和轮子还留在半空 | 细节透明度跟形状同步衰减不够快，改用 `Math.pow(backK, 3)` |
| **轮子看不出在转** | 纯白圆盘位移，像贴图平移 | 轮子必须有**十字辐条 + 中心轴**；`pField` 画不了转动，要用独立 `<g transform="rotate">`，转角 = 行驶距离 / 轮半径 |
| **线升起后地面消失** | `lineDelta` 把线抬去当屋顶，画面下半空掉 | 用 `pFold` 在同一条 y 上补一条黑线当地面 |
| **形变后脸留在原地** | 球变车了，五官还在球心 | `dot()` 里让 `x/y` 随形变进度从球心插值到"车头" |
| **元素在画外待太久** | 掉落/驶入时大半时间看不见，像突然冒出来 | 把 `viewBox` 抬高点留出空间，起点设在视野边缘内侧 |
| **音效起音无故超限** | 74ms（限 66ms），但音画明明对得上 | 前一个音效的尾音污染了基线窗口；`pop`（1.60s）前后 ±0.15s 内**不放任何音效** |
| **`linePts` 当成绝对坐标** | 线跑到画面外 | `linePts` 返回的是**每个顶点的偏移量**，不是目标坐标 |

## 八、形变（球→任意形状）的四条操作要点

1. **先定轮廓**：6–8 个拐点的闭合多边形最稳，拐角全用直线 —— 符合极简画风，也最好插值。
2. **中心选在球心**：车底比球底高时，底部半径会缩短，视觉上正好是"被轮子顶起来"。
3. **分方向错峰**：给每个角度一个 `delay`（按与"先长方向"的夹角算），形状就会有方向地长出来，比均匀放大生动得多。
4. **先形变、后补细节**：窗 / 轮 / 板条在 `k > 0.82` 之后淡入，否则会跟着形状一起被拉变形。

## 九、自定义形状（球变车 / 动物）的图层规则

母版图层从下到上：`线 → fx → props → 副球 → 手臂 → 主球身体 → halo → 五官`
（**手臂在身体之下** —— 所以它只露出球外的部分，看起来像"从身上长出去"）

| 想画的东西 | 该放哪 | 原因 |
|---|---|---|
| 车身/身体的**轮廓** | `dot().d` | 这就是角色本体 |
| 身上的**白色细节**（窗、板条、灯、花纹） | `dot().halo` | props 在下层会被身体盖住；halo 在上层且能同时当脸的白色底 |
| 车下**轮子**、货斗外框、烟、外部零件 | `props`（`pField`/`pFold`） | 在下层，正好"半嵌"进车身，不会盖住身体 |
| **五官** | 母版自动画（`face` + `x/y` + `rx/ry`） | 不用自己画，改 `x/y` 就能挪到"头"上 |

> 踩过的错：把货板条画在 `pField` 里，结果整条被蓝色车身盖住 —— 白色线条在蓝底上、又在身体下层，等于没画。

## 十、做 ced 族时补的两条

| 坑 | 现象 | 解法 |
|---|---|---|
| **"退去"看不出层次** | 线缩短后又在原地补一条地面，两条同色同粗接在一起，等于没退 | 补的地面用更淡的透明度（`pFold` 0.42），"深的是水、浅的是干地" |
| **举手像天线** | 用 `arm` 原语从球顶伸出，一根细杆顶个小环 | 改用 `pField` 两条斜线从球顶两侧外举（见 design-patterns.md 套路 15） |

**另外**：同一词族动作高度重复时（七个词都在"走"），不要靠"换个位置"区分，要靠**对象和方向**：
让给谁、抢在谁前面、路是在长还是在退、界限在不在、对手是谁、位子传给谁。七个维度，七个动作。
