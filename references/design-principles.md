# 设计原则（先读这一份，再动 scenes.js）

> 一句话：**一个词 = 一场小剧场。画面里出现的一切，都必须为"这个词的意思"服务。**
> 线和球只是起点，不是边界。

---

## 一、设计四问（逐词过一遍，答不上就先别写代码）

| # | 问题 | 决定什么 |
|---|---|---|
| 1 | 这个词的**画面主角**是谁？ | 可能是球、可能是线、可能是它们变成的东西（车、猫、栅栏） |
| 2 | 谁该**变身 / 变形 / 退场**？ | 线多余就让位（能滑走就滑走，整场都不再需要才淡出）；结构不够就长出细节 |
| 3 | 什么**动作**让人一眼记住词义？ | 动作类型由词义定，不由元素当前能力定 |
| 4 | 冻结那一帧，**单独能当单词卡**用吗？ | 冻结帧是观众停留最久的画面，也是记忆锚点 |

---

## 二、角色最小化：主球能演，就不要加副球

> 先分清两件事：本节说的是**角色**（会演戏的主体，比如副球）；第五节说的是**符号**（画面里的一件东西，比如一道栏、一枚印章）。角色宁少勿多，符号按需增删 —— 两套判据不冲突。

判断标准只有一条：**这个动作需要几个角色？**

| 动作拆开 | 角色数 | 要不要副球 |
|---|---|---|
| 搬运 = 搬的人 + 被搬的物 | 2 | 要（而且是**唯一**需要的情况） |
| 进门 / 出门 / 越沟 / 被压 / 回来 / 被赶走 | 1 | 不要 |
| 对比（重要的 vs 落选的） | 1 + 陪衬 | 用 `particles` 或几个小圆当陪衬，不当"角色" |

**副球不是常驻配角，是"事件道具"**：需要它出场的那一刻才出现，用完就退场。
反例：七场里灰球一直贴在主球头顶 —— 删掉它画面语义不变，说明它根本不该在场。

## 三、元素调色盘

### 线：它能变成一切"由线构成的东西"

| 手法 | 例子 |
|---|---|
| **重复** | 栅栏（多根竖线＋横杆）、雨丝、琴键、楼梯、牙齿 |
| **弯曲** | 桥（拱）、月牙、笑脸的嘴、绳圈、河流、问号 |
| **折角** | 台阶、城墙、山、门框 |
| **断裂** | break 的"啪"、闪电、裂纹 |
| **移动** | 传送带刻线、心电图、波浪、雨落下 |
| **退场** | 滑出屏幕、被球撞飞、被擦掉；淡出**只用于"整场都不再需要它"**的情况 |
| **反向出生** | 从球身上长出来（胡子、尾巴、轨迹）、从点炸成线 |

### 球：它是演员，能演任何角色

| 手法 | 例子 |
|---|---|
| **四边形/异形轮廓**（`dot()` 返回 `d`） | 车身、猫、箱子、苹果、云 |
| **长出部件**（`props` 自绘） | 三角耳＋胡须＋尾巴＝猫；翅膀＝鸟；斗＋轮＝卡车 |
| **形态即状态**（`shape`） | 压扁＝承压，拉长＝被拽，裂开（`split`）＝破碎 |
| **颜色即情绪**（`tint`） | 蓝＝常态，橙＝受惊/危险 |
| **轨迹即语义** | 弧线＝跳/扔，锯齿＝抖/怕，直线冲刺＝跑 |
| **多个球** | 一串＝排队/运输，大小对比＝大小，分合＝分/合 |

### 按语义类型的套路

| 词的类型 | 套路 | 例 |
|---|---|---|
| 具体名词 | 把线/球拼成那个东西 | fence＝竖线×N＋横杆；bridge＝线弯成拱 |
| 动词 | 球的动作就是词义 | jump＝弹起；push＝顶线移动 |
| 形容词 | 球的形状/颜色/状态 | big＝膨胀；sad＝嘴角向下＋变灰 |
| 抽象概念 | 球的处境作隐喻 | free＝挣脱线圈飞出；grow＝球变大＋长枝杈 |

## 四、进出场规则（**每个元素的出现和消失都必须合理**）

不能靠 `opacity` 淡入淡出**换角色** —— 那是"贴图切换"，观众看得出。用**位移**换场，让元素的来去自己说话。
唯一的例外：这个元素**整场都不再出现**（比如地面从此用不上了），可以淡出 —— 因为它不是"换"，是"退"。

| 方式 | 做法 | 用于 |
|---|---|---|
| **滚出 / 滚入** | 贴地压扁 5%、带扬尘短线、微笑；加速（`eIn3`）滚出画面 | 球退场、球返场 |
| **驶入 / 驶出** | 从画外进来、减速到停（`eOut`）、刹车胎痕、车头下沉；`eIn` 加速开走 | 载具 |
| **掉落** | 从上方加速落下（`eIn`）、落地压扁、三连弹（36→14→5px）、站定 | 球返场，比滚入更有戏 |
| **升起 / 吊走** | 整体 `lineDelta` 上移出画，或连箱带球一起升到画面上方停住 | 被运走、被驱逐 |
| **线变形退场** | 线自己收成一点、立成墙、滑出画面 | 地面不再需要时 |

三条配套铁律：

1. **出画 = 完全在画外**，不要"半截留在边上"（`x` 超出 viewBox 至少一个身位）。
2. **进场前必须有"空场"**：0.2–0.4s 的空镜，观众才知道上一个走了、下一个还没来。
3. **退场要有理由**：它是"跑掉""开走""被赶走"，不是"消失"。

## 五、元素按需增删（这条决定这套动画能走多远）

**元素不是固定的一套。** 球和线只是起点，为了讲清一个词，可以**现场造出原来没有的元素**，也可以把用不上的删掉。判断只看三条：

| 判据 | 结论 | 例 |
|---|---|---|
| 缺了它，这个词就演不出来 | **必须加** | cede（让）必须有一个「要走过去的人」，否则“让”没有对象 |
| 加了它，动作能少一句解释 | **值得加** | exceed 加一道界栏，“超过”不用靠字幕 |
| 删了它，画面语义不变 | **删掉** | 早期 port 的灰球一直贴头顶，删掉不影响任何一场 |

**常见误区**：把“加元素”理解成“加道具摆件”。
真正该加的是**这个词独有的那个符号** —— 印章、铃铛、雨滴、证件、界碑、枷锁。它只属于这一场，换一场就该消失。

### 新元素从哪来（四种找法）

| 找法 | 问自己 | 例 |
|---|---|---|
| 从**字面义**找实物 | 这个词摸得到的东西是什么？ | fence→栅栏（几根竖线）、stamp→印章（方块）、bell→铃铛 |
| 从**受力方**找 | 这个动作作用在谁身上？ | push→被推的箱子、support→压下来的重物、exceed→那道界 |
| 从**结果**找 | 动作做完留下什么？ | break→碎片、grow→新芽、recede→退潮的水痕 |
| 从**场合**找 | 这事发生在什么场景？ | passport→证件与关卡、report→纸与格线 |

### 一条铁律

**每个新增元素，都要能回答"它此刻在干什么"。**
答不上来就说明它是摆设 —— 摆设会稀释画面。宁可只有一颗球和一条线，也不要三个说不清用途的东西。

### 增删的时机

- **加**：在它"该出现的那一刻"出现，不要开场就摆在那儿（cede 的货是 0.5s 滚进来的，不是第一帧就在）
- **删**：换身份的用位移走（滚出、驶出、被吊走、掉下去）；**整场不再需要**的可以淡出
- **换**：一个元素可以中途换身份（灰球从“货”变成“被赶走的人”），但换身份的那一瞬要有动作支撑

## 六、反例清单（这些做法会被打回）

| 反例 | 为什么不行 |
|---|---|
| 七场都是"球站在线上做动作" | 球与线的关系只有一种，五场之后观众就腻 |
| 副球一直贴在头顶 | 位置装饰，不是事件，删掉也不影响语义 |
| 靠 `opacity` 换角色 | 观众看得出是换图，不是"它走了" |
| 元素凭空出现 | 破坏空间逻辑，观众会"出戏" |
| 为了用某个道具硬凑动作 | 道具服务画面，不是画面服务道具 |
| 冻结帧里球和道具同色糊在一起 | 观众停留最久的一帧，必须最清楚 |
