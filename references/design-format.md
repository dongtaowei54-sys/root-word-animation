# design.json 与 scenes.js 格式

工作目录下必须有两个文件：`design.json`（数据）+ `scenes.js`（动作逻辑）。`build-root.js` 把两者注入母版。

---

## 一、design.json

```json
{
  "root": "spect",
  "title": "看；观察",
  "words": [
    {
      "word": "spect",
      "prefix": "",
      "zh": "看；景象",
      "parts": [["spect", "看"]],
      "line": "flat",
      "voDur": 0.75,
      "speech": 0.62
    }
  ],
  "lines": {
    "flat": { "pts": [[92,196],[92,196],[300,196],[300,196]], "lw": 2.8 }
  },
  "cues": [
    [[0.05, "swish"], [0.62, "charge", 0.28], [1.70, "thud"], [1.60, "pop"]]
  ]
}
```

| 字段 | 说明 |
|---|---|
| `root` | 词根小写字母 |
| `title` | 只作备忘，不进画面 |
| `words[].word` | 整词，同时是配音文件名 `_vo/w_<word>.mp3` |
| `words[].prefix` | 前缀（无则空串），用于算最长词决定字号 |
| `words[].zh` | 中文释义，≤8 字，不带标点 |
| `words[].parts` | 词素分解 `[["dis","分开"],["tract","拉"]]` |
| `words[].line` | 引用 `lines` 里的键名 |
| `words[].voDur` | 配音槽长度，由 `tts.py` 自动回填 |
| `words[].speech` | 实测语音时长，由 `tts.py` 自动回填 |
| `lines{}` | 线型字典（见第二节） |
| `cues[]` | 每场一条音效表，数量必须与 words 相等 |

**`words` 的顺序就是播放顺序。**

## 二、线型（lines）

每条线是**4 个顶点**，路径为 `M0 L1 L2 L3`，顶点语义固定：

```
顺序：左顶(0)  左底(1)  右底(2)  右顶(3)
```

| 形状 | pts 写法 | 表达 |
|---|---|---|
| 横线 | `[[92,196],[92,196],[300,196],[300,196]]` | 承载、基准 |
| V 形漏斗 | `[[80,150],[187,248],[187,248],[294,150]]` | 吸入、汇聚 |
| Λ 形分叉 | `[[80,250],[187,152],[187,152],[294,250]]` | 分开、发散 |
| 杯形 | `[[86,158],[128,252],[247,252],[289,158]]` | 容器、内外 |

> 还能画门框 Π、箱体 U、台阶、竖墙等形态，写法见 `design-patterns.md` 套路 2。

**顶点配对铁律**：相邻两场之间的 4 个顶点会逐点插值做形变。左端两点必须都在左侧（先顶后底），右端同理。写反会让中间态扭成锯齿。

`lw` 是描边宽度，横线 2.8，斜线 3.2–3.4。

## 三、scenes.js

一个数组，与 `words` 一一对应：

```js
const SCENES = [
  {
    prefix: 'dis', zh: '分心；使分散', parts: [['dis','分开'],['tract','拉']],
    line: LINES.distract,
    from: LINK.afterAttract, to: LINK.afterDistract,
    dot(t)   { ... },      // 必填：球在这一刻长什么样
    fx(t)    { ... },      // 选填：粒子/波纹/墨迹
    cam(t)   { ... },      // 选填：镜头
    linePts(t){ ... },     // 选填：逐顶点形变（线的动态）
    lineDelta(t){ ... },   // 选填：整体位移
    lineLw(t){ ... },      // 选填：描边变化
    sub(t)   { ... },      // 选填：第二颗球
    props(t) { ... }       // 选填：道具（自绘）
  },
];
```

### 3.1 `dot(t)` 返回值

| 字段 | 取值 | 说明 |
|---|---|---|
| `x,y` | 像素坐标 | 球心 |
| `rx,ry` | 像素 | 半径；不等即变形 |
| `rot` | 度 | **只影响形状与 split 方向，不转表情** |
| `shape` | `round` `taper` `drop` `pinch` | 见下 |
| `face` | `focus` `love` `dizzy` `shock` `wow` `happy` | 表情 |
| `look` | `-1` `0` `1` | 只有眼球转，眼白不动 |
| `split` | `0 ~ 0.9` | >0.02 时球裂成两半，缝宽 = `split×8` |
| `tint` | `0 ~ 1` | 0 品牌蓝 `#1a6ff0`，1 受惊橙 `#ef5b3d` |
| `arm` | `{tx,ty,grip}` | 伸手抓某个点；`grip` 0–1 控制粗细与显隐 |
| `arm` | `{ang,len}` | 按角度伸手（目标点接近球心时自动隐藏） |

**四种形态**

| shape | 视觉 | 语义 |
|---|---|---|
| `round` | 正圆 | 常态 |
| `taper` | 尾端（−X）收尖 | 被拖着走、甩尾 |
| `drop` | 前端（+X）收尖 | 被吸、被抽出、下坠 |
| `pinch` | 腰被捏细、两端鼓 | 卡在窄口、被挤扁 |

**六种表情**：`focus` 眯眼待机 / `love` 心形眼 / `dizzy` X 眼 / `shock` 瞪眼小瞳 / `wow` 大眼 / `happy` 笑眼

**铁律**：表情按 `min(rx,ry)` 等比缩放，球被压扁时不会撑破轮廓 —— 这一点母版已处理，写动作时只需保证 rx/ry 不出现 0。

### 3.2 `cam(t)` 返回值

```js
{ k: 1.15, fx: 187, fy: 196, sx: 0, sy: 0 }
```

| 字段 | 说明 |
|---|---|
| `k` | 缩放，建议峰值 ≤ 1.25 |
| `fx,fy` | 焦点（舞台坐标），缩放围绕它 |
| `sx,sy` | 抖动偏移，撞击用 ±3px |

**必须满足**：`t = 0` 时返回 `k = 1`。否则换场会跳。母版在 4.42s 后自动把镜头拉回标准位。

### 3.3 `fx(t)` 可用原语

| 变量 | 类型 | 用法 |
|---|---|---|
| `fxShadow` | ellipse | 地面投影 |
| `fxRing` / `fxRing2` | circle | 冲击波（蓝 / 黑）；配 `pulse()` 用 |
| `fxDust` | path | 短促的碎屑线（尘土、撕裂） |
| `fxInk` | line | 拉丝、橡皮筋 |
| `fxSpeed` | path | 速度线（多段平行短线） |
| `fxTrailA/B` | path | 拖影，母版按速度自动算，不必手写 |

每帧开头母版会 `resetFx()` 清零，所以只在需要显隐时设置。

`pulse(t, t0, dur, x, y, r0, r1, op)` 返回 `{x,y,r,op}` 或 `null`，配合 fxRing 用。

### 3.4 道具原语（`props(t)` 里用）

母版提供 7 件现成道具，用 `opacity` 控制显隐，坐标为舞台坐标：

| 原语 | 调用 | 语义 |
|---|---|---|
| 书 | `drawBook()` + `pBookG.setAttribute('opacity', v)` | 该专注的对象；位置固定 `BOOK = {bx:138, b:196, w:44, h:50}` |
| 钩爪 | `drawClaw(cx, cy, R)` + `pClawG` | 外部力量把人勾走；`cx` 贴球缘，`R≈11` |
| 力场线 | `pField.setAttribute('d', 'M..L..')` | 沿内壁流动的吸力线 |
| 气流点 | `puffs[0..2]` + `pPuffG` | 拔出时的真空感 |
| 压缩褶皱 | `pFold.setAttribute('d', ...)` | 线段上的竖向刻度 |
| 虚线占位 | `pGhost` | 球被抽走后原地留空 |
| 虚线缺口 | `pHole` | 东西被拿走的位置 |

**写 `props(t)` 时先把自己的道具全部隐藏**（母版每帧会 `resetProps()`，但这只对默认逻辑生效；自定义 `props` 需要自己管）。稳妥写法：

```js
props(t) {
  const on = seg(t, 0.4, 0.3) * (1 - seg(t, 2.2, 0.4));
  pClawG.setAttribute('opacity', on.toFixed(3));
  if (on > 0.02) drawClaw(250 + 40 * eOut(seg(t, 0.4, 0.5)), 196, 11);
}
```

## 四、音效表（cues）

每场一条，元素为 `[场景内秒数, 音效名, 可选参数]`：

| 音效 | 用在 |
|---|---|
| `swish` | 球飞入（固定 0.05） |
| `charge` | 蓄力，可选增益 0.2–0.9 |
| `whoosh` | 高速位移，可选增益 |
| `thud` | 硬着陆、撞击、绷断 |
| `thoom` | 重物到位 |
| `tick` | 轻触、钩住、拉扯 |
| `riser` | 由远及近 |
| `pop` | 中文释义淡入（固定 1.60，与 `seg(t,1.60,0.42)` 对齐） |

**两条放音纪律**

1. **时刻只从动画的分支点抄**，不凭听感调。改动作就要同步改 cues，否则音画错位。
2. **`pop`（固定 1.60s）前后 ±0.15s 内不放任何音效** —— 也就是 1.45–1.75s 留空。原因：校验靠瞬态起音认音效，一旦有别的音效起音窗口和它重叠，前一个的尾音会被算进后一个，起音时长虚高（曾把 charge 的尾音算到 whoosh 头上，报 74ms，超 66ms 上限）。实在需要在这个窗口放，就把 `pop` 挪到该场更晚的分支点，并同步改 `seg(t, 1.60, 0.42)`。

## 五、时间轴常量（母版已固定，不要改）

| 常量 | 值 | 含义 |
|---|---|---|
| 每场动画长 | 5.2s | |
| `ANCHOR` | 4.42s | 冻结点：动作演完、词与释义都完整可见 |
| 冻结段 | `4.42 → 4.42+voDur` | 画面完全静止，播整词配音 |
| 收尾 | 到 `5.2+voDur` | 词与释义淡出 |

冻结段里母版把动画时间钳在 `ANCHOR = 4.42`：`dot()` **每帧仍在求值，只是拿到的 `t` 永远是 4.42**。
所以准确的说法是"t 不再增长"，不是"不再调用" —— 动作必须在此之前演进到完成态，因为 4.42 那一帧会被原样复制 `voDur` 秒。

## 六、画面布局基准（母版已定，场景不要各改各的）

| 项 | 值 | 说明 |
|---|---|---|
| 舞台 | 375 × 667（9:16） | |
| **SVG viewBox** | `0 -70 375 667` | 图形层整体下移 70px。**改布局只改这一个数**，场景坐标一律不动 |
| 地面线 y | 196 | 所有"站在地上"的坐标基准；图形实际显示在画面 **41.5%** 处 |
| 单词 `.word` top | 408px | |
| 释义 `.zh` top | 498px | |
| 词素行 `.gloss` top | 542px | |
| 图形底 → 单词顶 | 约 90px | 这段空档决定呼吸感，压到 60 以下会挤 |
| **场景坐标 y 上限** | **≤ 300** | 单词行顶端在 svg y=338，图形下沿过 300 就挤进文字区 |
| **场景坐标 y 下限** | **≥ −60** | 可视区从 −70 起；想出画用位移，不要用坐标硬顶 |

**为什么是 -70**：视图原点原来是 `0`，图形落在画面 30% 处，在 16:9 播放器里看明显偏上、且离单词太远（空档 128px）。下移到 41.5% 后视觉重心接近画面中心，空档收到 90px。

**只想微调时**：`viewBox` 第二项每 +10，图形再往下 10px（可视区底部相应上移）；文字只调 `.word / .zh / .gloss` 的 `top`。两边都不要动 `scenes.js` 里的 y 坐标。

## 七、扩展能力（v2026-10 新增）

### 7.1 `dot()` 返回自定义形状 `d`

球不再只能是圆/水滴——`dot()` 里给 `d`（闭合 path 字符串），母版直接画这个轮廓，**表情和手臂照常工作**。

```js
dot(t) {
  return { d: 'M142,188L142,158L204,158L204,144L238,144L246,164L246,188Z',
           halo: 'M211,151L234,151L236,165L211,165Z',   /* 车身上的白色细节（可选） */
           x: 223, y: 161,      /* 表情画在哪（可以偏离形状中心） */
           rx: 19, ry: 19,      /* 表情的尺度基准，与轮廓无关 */
           shape: 'round', face: 'happy' };
}
```

| 要点 | 说明 |
|---|---|
| `x / y` | 表情中心，车/动物这类形状要挪到"头"的位置 |
| `rx / ry` | 只决定五官大小，不再决定身体轮廓 |
| `halo` | **车身上的白色细节**：车窗、板条、车灯。可多段 `M...M...`，都用白色填充 |
| 为什么必须用 halo | 五官是深蓝 `#0f2b52`，画在蓝色车身上几乎看不见；`props` 的 `pField/pFold` 在球体**下层**，画在身上的东西会被车身盖住 |
| 拖影 | 自定义形状自动跳过同形残影，不会糊 |
| 形变 | 自己按角度采样插值（见 `design-patterns.md` 套路 1），凹角会被抹圆一点 |
| 车外附件 | 轮子、货斗外框、烟走 `props`（下层），正好"半嵌"进车身 |

### 7.2 `lineDelta(t)`：整条线平移

```js
lineDelta(t) { return [0, -120 * eInOut(seg(t, 1.55, 0.75))]; }   /* 线整体升到 y=76（当屋顶/梁） */
```

> **4.32s 之后母版会自动把 `linePts / lineDelta` 收回**（`back = 1 − eInOut(seg(t, 4.32, 0.70))`，防止换场跳变）。
>
> 冻结帧在 4.42s，此时 `back = 1 − 2×0.143² ≈ 0.96` —— **形变只留 96%，剩下 4% 要到 5.02s 才归零**。
> 后果按量算：偏移 20px 少 0.8px（看不出来），偏移 120px 少 4.8px（看得出"没升到位"）。
> 所以形变只用来**做过程**，冻结态的样子要由 `line.pts` 本身承载；非靠形变撑不可时，把目标值按 1/0.96 放大一点。

### 7.3 `pField` 自绘任意线稿

`pField` 是一条无填充的蓝线 path（stroke 2.2px），能画**任意多段**：方框、虚线、圆、箭头、车斗、纸格。

```js
/* 方框 + 三行字 */
pField.setAttribute('d', 'M128,150L238,150L238,192L128,192Z' +
                         'M140,163L226,163M140,173L218,173');
/* 圆（用两段 arc） */
'M' + (cx - r) + ',' + cy + 'a' + r + ',' + r + ' 0 1,0 ' + (2*r) + ',0a' + r + ',' + r + ' 0 1,0 ' + (-2*r) + ',0'
/* 虚线：用短横线段拼，间距 6–8px */
```

- 想要**黑色**线稿用 `pFold`（stroke #121316 2.2px）——补地面线、画板条、画刻度都用它
- 想要**虚线空位**用 `pGhost`（虚线圆）或 `pHole`（更小的虚线圆）
- 一次只能用一条 path，多个图形用 `M...M...` 拼在同一串里

### 7.4 `particles(t)`：粒子层（24 个）

```js
particles(t) {
  const p = seg(t, 0.30, 0.55);
  if (p <= 0 || p >= 1) return null;
  return [...Array(14)].map((_, i) => {
    const a = i / 14 * Math.PI * 2;
    const r = 6 + 54 * eOut(p);
    return { x: 187 + Math.cos(a) * r, y: 150 + Math.sin(a) * r,
             r: 3.4 * (1 - p), op: 0.8 * (1 - p), fill: '#8b9199' };
  });
}
```
超出 24 个自动忽略；传 `null` 全部熄灭。

### 7.5 副球当**物件**

`sub(t)` 默认灰色 `#8b9199`，`face:'none'` 就是"没有脸的货"。只在"动作必须两个角色"时用。

### 7.6 进出场用位移，不用透明度

```js
/* 退场：x 超出画面一个身位 */
const x = 194 + 250 * eIn3(seg(t, 0.55, 1.05));   /* 194 → 444，画外 */
/* 返场：从上方掉落 + 落地弹跳（见 design-patterns.md 套路 10） */
```
`opacity` 只在"画外待机"时用，不要用它做转场。

### 7.7 `root`：每场可切换词根拼写

同一词族常有几种写法（ced / ceed / cess、tain / tent 等），母版默认全片只用一个。

```js
{ root: 'cede', prefix: 'pre', zh: '先于；居前', parts: [['pre','前'],['cede','走']], ... }
```

`setScene` 见到 `root` 就改 `#rootEl` 的文字，所以这一场会显示 `precede`，下一场写成 `root:'ceed'` 就显示 `proceed`。
**不在 `design.json` 里写，写在 `scenes.js` 每场对象上**；`design.json` 的 `root` 只决定输出文件名和默认值。
